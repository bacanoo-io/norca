# Upstream Nomad documentation (reference)

`content/` holds the documentation text of HashiCorp Nomad v1.6.5, licensed under
MPL 2.0, kept unchanged as a reference for the code this fork is based on.

The documentation website itself (its build scaffolding, design, branding, images
and navigation data) was removed; it is not part of Norca. Image links in the text
(`/img/...`) therefore point to files that are not in this repository.

The text describes Nomad v1.6.5. It does not cover every Norca extension, and
product names, URLs and commands in it refer to upstream Nomad. Norca's own
documentation is in the `docs/` directory at the root of the repository.
